# Traditional Delights - Professional Website

A modern, responsive website for traditional laddu, dry snacks, and roasted dry fruits business.

## Features

### 🎨 Professional Design
- Modern, clean design with warm colors
- Fully responsive layout for all devices
- Smooth animations and transitions
- Beautiful gradient backgrounds
- Professional typography using Poppins font

### 📱 Interactive Elements
- **Mobile-friendly navigation** with hamburger menu
- **Product filtering** by category (All, Laddu, Dry Snacks, Roasted Dry Fruits)
- **Contact form** with validation
- **Animated counters** for statistics
- **Scroll animations** for engaging user experience
- **Notification system** for user feedback

### 🛒 Product Showcase

## Getting Started

1. Open `index.html` in any modern web browser
2. For local development, use a local server:
   ```bash
   python -m http.server 8000
   # or
   npx serve
   ```

## Customization

### Colors
Primary colors can be changed in `styles.css`:
- Primary: `#ff6b35` (Orange)
- Secondary: `#f7931e` (Light Orange)
- Dark: `#333` (Dark Gray)

### Content
- Edit `index.html` to change content
- Update product information in the Products section
- Modify contact details in the Contact section

### Styling
- All styles are in `styles.css`
- Responsive breakpoints: 768px and 480px
- CSS Grid and Flexbox for layouts
